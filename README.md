# LNG Market Data Analysis Independent Project

## Developed a Python/SQLite backtesting platform ingesting 10+ years of energy settles across 7 series (WTI, Brent, Henry Hub, RBOB, ULSD & CL1/CL4) via the EIA API, with 3:2:1 crack-spread, WTI term-structure (contango/backwardation), natural-gas seasonality analytics and vectorised technical indicators. Built an event-driven backtester with volatility-targeted position sizing, stop-loss controls and transaction costs across 2 systematic strategies, achieving a net Sharpe of X and max drawdown of X % win rate.
